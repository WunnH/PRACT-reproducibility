# PRACT Reproducibility Materials

This repository provides supplementary methodological parameters and aggregate reproducibility information corresponding to the PRACT manuscript.

Included information:

- T1WI, T2WI, and SWI acquisition parameters and voxel sizes
- spatial mapping to the patient-specific T1WI planning space
- uncertainty perturbation scenarios and physical magnitudes
- anatomically constrained candidate trajectory generation
- nominal and robust candidate-set statistics
- computational runtime statistics

No source code, patient-level data, images, masks, coordinates, entry points, or individual trajectories are included.
